# 🧮 Calculadora

Calculadora desenvolvida durante meus estudos de desenvolvimento web.  
O projeto permite realizar operações matemáticas básicas por meio de uma interface responsiva e intuitiva.

## 🔗 Acesse o projeto

Você pode utilizar a calculadora pelo link abaixo:

[Usar a calculadora](https://maria-d-soares-dev.github.io/calculadora/)

## 📸 Interface

A calculadora possui uma interface responsiva, com fundo escuro, detalhes em tons de roxo e indicação visual para resultados válidos e mensagens de erro.

## ✨ Funcionalidades

- Soma;
- Subtração;
- Multiplicação;
- Divisão;
- Validação de divisão por zero;
- Exibição da operação completa;
- Indicação visual de sucesso;
- Indicação visual de erro;
- Layout responsivo para computadores E celulares.

## 🛠️ Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5.
